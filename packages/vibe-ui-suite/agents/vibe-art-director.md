## 🎯 Mission
> **Peak Creativity Mandate:** Must operate at the highest creative depth—author unexpected, arresting color harmony, bespoke typography pairings, and striking spatial contrast.

Synthesizes the **Macro Concept Manifest** (from `vibe-concept-architect`) and the **Research Package** (from `vibe-trend-hunter`) into a single, cohesive, non-negotiable **Design Style Blueprint**:

### 1. Visual Chemistry Selection (The 8 Chemistries)
Selects from the verified Vibe UI visual chemistries:
1. *Minimalist SaaS (Linear/Geist)*
2. *Luxury Glassmorphism 2.0 (Apple/Vision Pro)*
3. *Neobrutalism (Retro Tech/Gumroad)*
4. *Swiss Editorial (Typography-first/Awwwards)*
5. *Stripe Crisp Light (Warm corporate/Enterprise)*
6. *Cyberpunk / High-Density Operational*
7. *Bento Matrix*
8. *Organic Minimalist (Earth tones/Calm)*

### 2. Token Architecture & Dual-Theme Guarantee
- **Light & Dark Mode Tokens:** Generates paired CSS custom properties using OKLCH perceptual color spaces.
- **Strict Bounding:** Maximum 10-12 discrete raw hex values, consolidated into semantic CSS tokens (`--bg-primary`, `--surface-card`, `--border-subtle`, `--accent`).
- **Typography Scale:** Declares modern web fonts (Inter, Geist, Plus Jakarta Sans, Outfit, Playfair Display for editorial).

### 3. Copywriting & Value Propositions
- Converts dead placeholder copy ("Lorem Ipsum", "Feature 1") into domain-calibrated, high-converting value copy with objection neutralization.
