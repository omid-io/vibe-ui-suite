# 🍏 Vibe UI Suite v4.1.0 — Apple Cupertino Design & Kowalski Motion Physics Ergonomics

We are thrilled to release **Vibe UI Suite `v4.1.0`**, introducing the **6th Master Visual Chemistry archetype (Apple Cupertino Fluid & Human Interface)**, high-fidelity physical spring dynamics distilled from Emil Kowalski's motion engineering principles, mobile-native touch resilience, and automated motion ergonomics auditing in `PhysicalCritic`.

---

## 🌟 What's New in v4.1.0

### 1. 🍏 6th Master Visual Chemistry: Apple Cupertino Fluid & Human Interface
Formally integrated into `skills/visual-chemistry-engine` and the offline React 19 compiler (`vibe_core/generator.py`):
- **Translucent Chrome**: Multi-layer frosted navigation bars and floating toolbars (`backdrop-filter: blur(20px) saturate(180%)`) with background content scrolling cleanly underneath.
- **Adaptive Transparency Fallback**: Explicit `@media (prefers-reduced-transparency: reduce)` high-contrast solid backgrounds.
- **Continuous Squircle Curvature**: Smooth Apple-style squircle radii (`rounded-[28px]` on containers, `rounded-[22px]` on nested cards).
- **Optical Typography Sizing**: Dynamic optical tracking (`letter-spacing: -0.025em; line-height: 1.08;` on display headers, comfortable `1.5` leading on body copy).
- **Apple System Accents**: High-fidelity Apple System Blue (`#0071e3` / `oklch(0.58 0.22 255)`) with guaranteed WCAG 2.2 AAA text contrast.

### 2. ⚡ Kowalski Motion Physics & Critically Damped Springs
Overhauled `skills/vibe-physics-engine` with production-grade motion ergonomics:
- **Critically Damped Springs**: Replaced crude easing curves with natural physical spring mechanics (`damping: 1.0`, `response: 0.35s`) eliminating unnatural overshoot and rubbery bounce on UI controls.
- **Velocity Handoff & Direct Manipulation**: 1:1 displacement tracking during touch drag, handing off release velocity into spring momentum equations with progressive logarithmic rubber-banding.
- **Asymmetric Enter/Exit Timing**: Deliberate, informative entry transitions (200ms - 300ms) paired with instant, non-blocking exit transitions (<180ms ease-out).
- **Keyboard Action Invariant**: Zero animation latency on keyboard shortcuts (⌘K, Escape, Tabs). Power-user interactions must execute with zero delay.
- **GPU Off-Main-Thread Acceleration**: Mandated composite layer transforms (`translateX` instead of JS-loop layout properties) to eliminate dropped frames under load.

### 3. 📱 Mobile-Native Touch Polish & Safari Ergonomics
Expanded `skills/ui-kit` with essential mobile invariants:
- **Dynamic Viewport Height (`100dvh`)**: Eliminated mobile browser address bar layout jumps.
- **iOS Safari Input Auto-Zoom Guard**: Mandated base font-size $\ge 16\text{px}$ for all mobile form controls.
- **Tap Highlight Suppression**: Stripped WebKit default gray tap flash (`-webkit-tap-highlight-color: transparent`) and eliminated 300ms touch delay (`touch-action: manipulation`).
- **Sticky Touch Hover Elimination**: Strictly gated hover pseudo-classes behind `@media (hover: hover) and (pointer: fine)` to prevent mobile buttons from remaining stuck in hover states after tapping.

### 4. 🛡️ Automated Motion Ergonomics Inspection & Self-Healing
Armed `vibe_core/physical_critic.py` and `vibe_core/refiner.py` with automated anti-slop gates:
- **`audit_motion_ergonomics()`**: Automatically inspects DOM and CSS for 5 motion anti-patterns:
  1. `transition: all` layout recalculation jank
  2. `scale(0)` comical pop-in (mandates initial `scale(0.96)` with `opacity: 0`)
  3. Excessive micro-interaction duration (> 300ms)
  4. Missing `@media (prefers-reduced-motion)` accessibility guards
  5. Sticky mobile touch hover states
- **Surgical Self-Healing in AutoRefiner**: Automatically rewires `transition: all` to explicit transforms, fixes `scale(0)` to `scale(0.96)`, and injects `prefers-reduced-motion` fallbacks.

### 5. 🤖 End-to-End Pipeline & Director Natural Language Routing
- **`DesignDirector.infer_intent()`**: Automatically recognizes natural language style requests for Apple, Cupertino, iOS, macOS, and Persian "طرح اپل", assigning `selected_style = "apple_cupertino"`.
- **`InterfaceGenerator.apply_style_architecture()`**: Renders authentic Apple Cupertino layouts, squircle cards, and System Blue primary CTAs.
